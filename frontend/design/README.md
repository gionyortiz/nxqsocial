# NXQ Social premium dark redesign

The visual target for this worktree is the user-selected premium-black concept
generated on 2026-08-29. The implementation should preserve NXQ Social's
existing features while following these durable rules:

- Near-black and midnight surfaces carry the interface; magenta is an accent,
  not a background treatment.
- Panels use subtle borders and restrained shadows instead of nested card
  stacks or heavy glass effects.
- Navigation, body copy, and interaction labels must remain readable at normal
  desktop and mobile sizes.
- Stories remain a compact horizontal rail on every breakpoint.
- Trust and verification cues use cyan/emerald; destructive states use red.
- Existing APIs, routes, auth flows, safety controls, and social interactions
  remain unchanged by visual work.
